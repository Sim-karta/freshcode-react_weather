# Weather

Пустой React-проект на Vite с базовой структурой Feature-Sliced Design.

## Структура `src`

- `app` — инициализация и корневое приложение.
- `pages` — страницы.
- `widgets` — крупные самостоятельные блоки интерфейса.
- `features` — пользовательские действия и сценарии.
- `entities` — бизнес-сущности.
- `shared` — переиспользуемые ресурсы (`ui`, `lib`, `assets`, `types`).

Слои и каталоги для будущих модулей оставлены пустыми. Стили, API- и конфигурационные каталоги не добавлены.
